# Salary-Predictor
A Machine Learning project that predicts an estimated salary based on a person's years of work experience using Simple Linear Regression. The project uses Python, Pandas, Scikit-learn, Joblib, and Streamlit to train the model and provide an interactive web interface for salary prediction
